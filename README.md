## What was built?

CityNexus explores a persistent, agent-assisted city journey rather than a single AI-generated itinerary: understand a traveller's natural-language goal; discover and verify candidate venues; compare plans and mobility options; display a map, budget and schedule; explain Agent/tool activity; and ask for human approval before material plan changes. Later work investigated Guardian context checks, multi-person journeys, private Pocket Walks and simulated multi-day classroom trips.

This repository is the **original engineering archive**: implementation branches, experimental notebooks, tests and authentic Git commit history. It is **not** a one-click hosted production application. The complete live system was not successfully demonstrated to the professor in class.

## Distinguishing a real run from a simulation

- **Live provider requests** mean real HTTP evidence from a named provider; they do not mean the traveller physically went there.
- **Controlled browser or test fixtures** demonstrate the specified UI/API transitions, not availability of every external system.
- **Simulated time, GPS and activity completion** were specifically developed for classroom demonstrations. They are never presented as physical-arrival proofs.
- **Different development branches** are not claimed to be one verified merged release. The published portfolio's credential-redacted snapshot was not freshly retested as a complete end-to-end deployment.
