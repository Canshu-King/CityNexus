## Revolution principle

The point is not to make two models appear concurrent.

The point is to make concurrency survivable.

A response may arrive after its reality died.

A newer Agent may act first.

A stale Agent may wake after the newer Agent has already committed recovery.

None of those timing orders may transfer authority.

The server must be able to prove, from durable facts:

- which run made each external call;
- which reality generation that run belonged to;
- whether its response was still spendable;
- which proposal earned collective authority;
- which single mutation was legal;
- and why stale work remained causally inert.

That is the Revolution boundary.
