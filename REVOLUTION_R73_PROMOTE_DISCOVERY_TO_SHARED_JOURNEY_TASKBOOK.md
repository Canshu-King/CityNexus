## Revolution promise
Today CityNexus can spontaneously discover a real Place (R66/R67), invite companions (R70), assess a member's detour (R71), and coordinate independent visits (R72). But it cannot turn a great spontaneous find into an **actual mutually authorized change of the one shared Journey**.

The user story:
> "We discovered this incredible public garden. Shall we make it an official stop in today's group itinerary?" — A proposes. B and all other required current Journey members see the *exact same grounded trade-off* and independently answer. If existing governance and route/commitment constraints pass, CityNexus offers/activates the adjusted authoritative shared plan. If not, it explains what blocks the change and everyone retains their original trip.

**Do not build another voting toy.** This strike must integrate a *real proposal-to-authorized-shared-plan path*, not merely a “poll finished” badge. Be bold about the product; be strict about actual authority.
