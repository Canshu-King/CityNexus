## Why R79 must be a Revolution capability
R76: C independently joins. R77: C can request a private route toward the *planned* shared stop (provider evidence remains optional/UNKNOWN). R78: C can self-report needing coordination, and A can sign a help acknowledgement. But **“I can help” does not tell C where A intends to meet**. R79 turns the help acknowledgement into a practical, consensual *two-person* public-place handoff while leaving the entire shared Journey and C3/C4 commitments intact.

The single human story:
> C (ordinary signed collaborator) presses “I need help coordinating”. A (signed owner or any authorized in-force companion) explicitly acknowledges. A offers **“I can meet you at [specific public landmark]”**, C sees exactly which place, how it was sourced and the time window, and accepts or declines independently. A and C can each open that exact public landmark pin after separate map consent. Neither can see the other's precise current location or infer arrival. The rest of the group Journey remains unchanged.

**Not** a generic chat room, broad location sharing, a new collective replanning mechanism, automatic physical meetup detector, or an R69/R62 reunion shortcut.
