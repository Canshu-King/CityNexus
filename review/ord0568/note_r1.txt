WHAT CHANGED (two product files, one ruler)
  frontend/src/lib/displayVocabulary.ts  a closed table `ROUTE_PROVENANCE` with the six names the server can
      write into `route_provenance`, each with a Chinese and an English wording, and
      `routeProvenanceLabel(value, zh)` which answers only with one of this file's own sentences. An
      unlisted value gets "这台服务器写了一个这屏不认识的证据来源" / "this server wrote an evidence source
      this screen does not know" -- it is never printed back. The shared `pick()`/`rawChannel()` fallback is
      deliberately not used: one call site that echoes an upstream read condemns every panel that imports a
      `pick`-based label, which is the defect ORD-0551 r3 had to take back.
  frontend/src/features/recovery/V14RecoveryTruthPanel.tsx  the cell now reads
      `<provider> · <ENUM>（<words>）`. The provider key and the enum stay exactly as written: they are what
      the backend logs and the contract name, and the ruling was that the audit reading has to be able to
      match them. Only the bracket changes.
