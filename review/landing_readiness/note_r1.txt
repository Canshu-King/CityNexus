Landing readiness -- one question, answered from the server's bytes: can each open branch still be landed
on the current authoritative tip without overwriting somebody else's change?

WHY
  The authoritative line is a rebuilt, parentless tree, so ancestry says nothing, and a branch can go from
  pure-apply to clobbering between the minute it was cut and the minute it is landed. That is exactly what
  happened to review/cff87c64-ord0562-english-count-nouns-r4: the tip moved over the same component file
  while its block waited to be landed. This ruler reads blob equality instead and says which of the three
  states each file is in.
