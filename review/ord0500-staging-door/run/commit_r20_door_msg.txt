ORD-0500 phone lane: put the refusal door inside the staging tool, with arms that prove it bites

The page door (built for 裁① at 04:26) refuses to emit a page on red readings. The upstream leg --
stage_readings_r6.py, the tool that copies those readings into the tree the commit will carry -- had no
door at all: it wrote whatever it was handed and exited 0, so a red receipt could reach a commit and the
page would only notice later.  This is the same rule bolted to the door that performs the write.

tools/stage_door_r20.py
  - judges the ten receipt-derived items of the page door's eleven, reading the STAGED bytes rather than
    the copies in the lane's evidence dir; the three remote-side items are named NOT_THIS_DOOR instead
    of being silently dropped.
  - a missing or unparseable receipt is a RED item, not a skipped one -- reading "absent" as "fine" is
    the one-directionally-blind ruler this lane has been corrected for twice.
  - on red it restores every byte it wrote (rewrites what changed, deletes what it created) and raises
    STAGING_READINGS_RED with a named failure sheet, so the tree that the next `git add` would pick up
    is the tree that was green.
  - R20_FORCE_STAGING_RED=<check name> is its arm: it injects a verdict without touching any receipt.

Proved, not described:
  - tools/stage_door_r20_mutants.py -- six arms against scratch copies only (with a guard that refuses
    to run if the scratch destination resolves inside the shared worktree): C1 control GREEN; M1 flips
    the citation gate's verdict, M2 deletes the anchor re-check, M3 truncates the vocabulary receipt so
    it no longer parses, M4 adds a stray file and goes red; C2 reverts and passes again.  All four
    mutants bit, both controls stayed green, and every case ended byte-identical to its own snapshot
    (evidence/stage_door_r20_mutants.json).
  - tools/stage_door_r20_receipt.py -- re-runs the REAL staging tool twice in one window: forced red
    exits 1 with a 2626-byte sheet and `git status` back to what it was, control exits 0 with
    staging_door GREEN and its 8 written paths restored (evidence/stage_door_r20.json).
