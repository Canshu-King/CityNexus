"""收藏状态唯一性那栋楼 · 第二格：把"只增不减"那族的状态组合逐枚枚举，并给尺配"该红的那一次"。

第一格量到的缺口：取消收藏零枚门（屏上 0、served contract 0）。这一格要做两件事：
1. **枚举**：图纸点名的两种不一致（"已收藏但列表没有"、"列表有但接口说没有"）在这棵树上
   能不能造出来。逐个组合试，造得出来 / 造不出来都算读数——造不出来也要说清是被哪道门挡住的。
2. **让尺会红**：这把尺判"接口与屏上一致"，那它必须有一次"该红的那一次"。做法：
   干净臂（接口删了一行、屏上不刷新）必须被尺判红；负对照（接口与屏上同步删）必须判绿。
   不然这把尺是恒绿的假锁。

只读 + 私有栈；产品字节零改动（"接口层做一次删"是在私有库里直接改行，走真读回，不写产品代码）。
"""

def free_port(want):
    import socket
    p = want
    while p < want + 120:
        if p not in FORBIDDEN:
            with socket.socket() as s:
                try:
                    s.bind(("127.0.0.1", p))
                    return p
                except OSError:
                    pass
        p += 1
    raise SystemExit("REFUSED: 找不到私有端口")


def http(url, data=None, headers=None, method=None, timeout=60):
    req = urllib.request.Request(url, data=data, headers=headers or {}, method=method)
    try:
        with urllib.request.urlopen(req, timeout=timeout) as r:
            return r.status, r.read()
    except urllib.error.HTTPError as e:
        return e.code, e.read()
    except Exception as e:  # noqa: BLE001
        return None, str(e).encode()[:120]


api = free_port(5191)

    env.pop(k, None)

out = {"run_id": run_id, "api": api, "steps": [], "combos": [], "discriminator": {}, "BAD": BAD}
try:
    for _ in range(90):

    jid = json.loads(b).get("journey_id")
    st, b = http("http://127.0.0.1:%d/api/v1/journeys/%s" % (api, jid))
    j = json.loads(b)
    tid = j.get("traveler_id") or (j.get("journey") or {}).get("traveler_id")
    # 建一层
    st, b = http("http://127.0.0.1:%d/api/v1/collections?traveler_id=%s" % (api, tid),

    shelf = json.loads(b)
    out["shelf_id"] = shelf.get("id")
    # 取一枚能收的地点（场景那枚）
    # 屏上读的那一扇是 /journeys/{id}/experience；place_id 在 active_plan.activities[].place_id。
    # 直接读 journey 本体拿不到（那上面没有 place_id）——我第一版就栽在这。
    st, b = http("http://127.0.0.1:%d/api/v1/journeys/%s/experience" % (api, jid))

    out["place_id"] = place_id
    if not place_id:

    def list_api():

    out["discriminator"] = {
