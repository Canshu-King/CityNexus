  system: the font-size bucket holds 0 entries. So the sizes are not in the resource table at all.

NOT CLAIMED, NAMED AS THE NEXT SLICE
  * Colours were not touched. The reference's alpha axis is 0/10/15/25/50 while our tint ladder is
    4/6/8/10/40/50/60, so four of our seven tint tiers sit off their axis; moving them changes hairline
    and shadow strength, which is a contrast question, not a naming one, and it needs the contrast gate
    decided first -- this file is the measurement for that decision, not the decision.
  * Only the View layer was measured. Sizes written in compiled code (the Compose side) were not
    extracted, so 'the whole ladder' here means the 127 values the layouts actually paint.
  * The 347 off-ladder spacing literals named here (167 on the four new tiers alone) were migrated only
    where the value was unchanged: 12 divider sites and 11 font sites now read the token, 167 padding /
    margin / gap literals now read --cn-s-2/4/6/10. Any further migration changes geometry and is its own order.
