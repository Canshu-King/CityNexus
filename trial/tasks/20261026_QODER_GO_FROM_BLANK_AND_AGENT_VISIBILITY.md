## 第 2 刀：把 Agent 真的做了什么显示在屏幕上

1. 课堂 `ClassroomPresenterPanel.tsx` 当前只从 run progress 消费 proposal/outcome/events，后台真实 `AgentRunStep` 可能已落库，用户屏上还会看到“暂无助手运行记录”。基于真实的 `GET .../simulation/runs/{rid}/progress`（以现代码契约为准）增加 **当前 run 关联的、可展开的工具执行时间线**：正在查地点 / 读取行程 / 路线与资料 / 完成 / 失败原因，显示工具名、状态、步骤数、时间和下一动作。只展示安全投影，绝不泄漏模型私有正文、凭证或工具敏感参数，也不要生成虚假思考过程。
2. 当前事件提案的“接受”旁，展示本次新旧计划的**实际增删活动、时间变化、费用差额**，缺费用来源则写未知；同一事件 id/proposal id 绑定。用户接受成功，主动刷新外层 Journey、PlanVersion、当前活动、地图和状态，不要再让旧故宫停留到手动刷新后才改成天坛。
3. 同样的信息尽可能进入正常旅行的 Agent 工作区，而不是只加一个讲台控制台；界面保持一条自然的用户主路径，调试细节放展开区。
