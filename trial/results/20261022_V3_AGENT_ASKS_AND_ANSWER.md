# Agent 真的在问，也真的答了：一句话 → 选项 → 阶段性成果（2026-10-22）

一句话：**接管令 P0 里「Agent 询问或研究」这一段，今天有真读数了**——不是转圈动画，是模型问出带北京内容的问题、旅客按它给的选项回答、服务端把两次回合与步骤落库。

## 这一趟怎么走

1. 首屏「想怎么玩？」里打一句话：「想慢慢逛北京的古迹和胡同小吃，一天别太赶。」目的地填「北京」，出发日期 2026-11-02，按「开始」。
2. 行程建完落在工作台。点「对话」层，打开「连接与公开地点来源」，勾上「本次允许 AI 处理旅行目标（可能产生费用）」（「本次允许查询公开地图和地点来源」故意不勾，原因见下面）。发送键从灰变可点，屏上徽标是「AI 建议可试」。
3. 发出去之后，服务端建了任务（`POST .../agent/goal-tasks` → `ACCEPTED`），第一个回合 14.4 秒，落库一步 `ask_traveler:COMPLETED`，任务转 `NEEDS_DECISION`。
4. 屏上出现 Agent 的问题「第一天想以哪种古迹路线为主？」和四枚选项，内容是北京的：「故宫+景山一线（推荐）上午逛故宫、下午登景山俯瞰全城，顺路在周边胡同吃小吃。经典且节奏自然，适合不赶路。」「天坛+前门大栅栏 上午天坛看祭天建筑，下午前门/大栅栏逛老字号、尝小吃，整体更轻松平缓。」（截图 `20261022_V3_AGENT_QUESTION_390.png`）
5. 按第一枚选项（真实点击，不是打字）。第二个回合 35.1 秒，`agent_runs.status=COMPLETED`、outcome `SUMMARY_READY`，任务转 `PARTIAL_READY`，屏上徽标变成「已有阶段性成果」，工具结果块写着「工具结果 · 1 次」。
6. 整页刷新：任务还在同一状态、同一枚任务号，屏上「你的旅行草案」区块仍在。

## 这一趟**没有**拿到的那一格

「改某半天」没在这趟里完成，原因说清楚：草案的 `revision` 还是 0、`days` 里没有任何 slot（屏上「按天调整行程 0 项安排 · 2 天」）。模型这轮给的是**摘要**而不是排好的日程——因为这趟行程是旅客用一句话建的，服务端给它的是私有城市码（库里 `city_code` 形如 `CN-RV-…`，规范地名走结构化 brief，见 `backend/app/agent/goal_artifacts.py:81`），离线目录里的北京地点并不挂在这个私有码下；要把地点带进来只有两条路：**公开来源研究**（这格勾上的话），或者旅客自己在日程层动手改。前一条今天走不了：本机直连 `overpass-api.de` 与 `wikidata` 是 TLS 握手超时，走本机代理是 `SSL UNEXPECTED_EOF`（与 `api.github.com` 同一形状），两条路都是现读失败。所以这一格改由后一条路验：在「日程」层的草案编辑器里加/改半天的安排，走 `PUT .../goal-tasks/{id}/draft`，读数在 `20261022_V3_AGENT_HALFDAY_*`。

## 也不宣称的事

- 两次回合都是模型真答的（本机网关、零扣费档、密钥只进子进程环境变量），但**一次外部地点供应商都没调成**；屏上出现的故宫、景山、天坛是模型自己的话，没有落成地点行，也没有营业时间、票价、照片——它们仍是 `UNKNOWN`，这一棒没有把它们写成 verified。
- 屏幕是本机 Chromium 的窄视口，不是手机在手里的点击，`USER_VERIFIED` 继续 PENDING。
- 多人那一面没动：这枝只给发起座位 `JOURNEY_UPDATE`（`backend/app/db/session.py:241`），裁语未下之前不扩权。
