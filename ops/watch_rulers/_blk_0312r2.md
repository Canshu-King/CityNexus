- 裁定的原话方向：`M1a` 与 `M1b` 不许共用一条判据，因为**故障责任链不同**——`M1a` 是 client → vite/proxy → 代理自答生成的 500；`M1b` 是 client → proxy → 后端应用 → 应用生成的响应。两者在用户屏幕上可以长得完全一样（`HTTP 500` + `text/plain`），所以只看状态码与 content-type 无法归属。
