## Revolution user story: plans break in the street
A normal traveler reached stop 1 (or says they did), then discovers the planned second stop is closed, inaccessible, packed, or simply undesirable. A static plan or a blind progress reset is an awful companion. From GO MODE the traveler needs:
**“Second stop won't work” -> see the saved alternative with its real OSM source and age -> compare walking leg if I consent -> “Take this alternative” -> continue the same walk, retaining only MY self-reported completion of stop 1**.

This must be a deliberate, bounded recovery, not a guessed closure or agent mutation.
